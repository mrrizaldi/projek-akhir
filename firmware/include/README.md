# firmware/include/: contract headers

| Header | Contents | Origin |
|---|---|---|
| `model_int8.h` | INT8 TFLite model as a C array, with scale and zero point | GENERATED by `model/scripts/export_model_h.py` |
| `ecg_preproc.h` | Bandpass coefficients and preprocessing constants from `model/src/preprocessing.py` | GENERATED by `model/scripts/export_golden.py` |
| `ecg_pipeline.h` | On-device preprocessing contract (must match Python) | hand-written |
| `ecg_live.h` | Contract for the sample → beat streaming flow | hand-written |
| `ecg_mqtt.h` | Contract for the MQTT payload and queue | hand-written |
| `ina219.h` | INA219 register conversion | hand-written |
| `board.h` | PCB rev1 pin map and device wiring (TFT, buzzer, buttons, ADC) for `main.cpp` and the `test_hw_*` tests | hand-written |
| `acquisition.h` | 360 Hz timer ISR, sample queue, ADC / reference replay / recording replay sources | hand-written |
| `gate.h` | Signal quality and calibration phase | hand-written |
| `classifier.h` | Per-beat TFLM inference and publication to the MQTT queue | hand-written |
| `display.h` | TFT (monitor and menu screens), NeoPixel, buzzer | hand-written |
| `buttons.h` | Debounce and events for buttons B1–B3 (800 ms long press), serial injection events | hand-written |
| `menu.h` | On-device menu: open, forward button events, 1 Hz text pages | hand-written |
| `diagnostics.h` | `diag_*` device tests for the "Tes perangkat" (device test) menu and `test_hw_*` | hand-written |
| `recorder.h` | Numbered recordings `/rekam/NNN.csv` on LittleFS | hand-written |
| `power.h` | INA219, `p0`–`p5` power measurement ladder, standalone ladder with `/daya/NNN.csv` results | hand-written |
| `app_settings.h` | WiFi/broker list; WiFi, broker, and signal source choices in NVS | hand-written |
| `serial_cmd.h` | Serial commands | hand-written |
| `wifi_secrets.example.h` | Credentials template; copy it to `wifi_secrets.h` (git-ignored) | hand-written |

GENERATED headers must not be edited by hand. Regeneration:

```bash
cd model && make quantize && make export    # model_int8.h (lewat scripts/export_artifacts.sh)
cd model && python scripts/export_golden.py  # ecg_preproc.h + firmware/test/golden_ref.h
cd firmware && pio test -e native            # verifikasi C == Python
```
